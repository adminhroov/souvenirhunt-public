# SouvenirHunt

XREAL One Pro 안경 + Beam Pro로 하는 XR 인형뽑기 게임입니다. 이 갈래(`main`)는 **B 앱(B SouvenirHunt, com.hroov.souvenirhunt.b)** 의 Unity 프로젝트입니다.

- 변경 내용: [CHANGES.md](CHANGES.md)
- 설치 파일(APK): [Releases](https://github.com/adminhroov/souvenirhunt-public/releases) — 게임 APK와 실행 앱(Launcher) APK를 둘 다 설치하고, 실행 앱으로 시작해 첫 화면에서 한국어 / English를 고릅니다. `SHA256SUMS.txt` 로 파일을 확인할 수 있습니다.
- 갈래: `main` = B 앱, `a-line` = A 앱
- 개발 환경: Unity 6000.0.79f1, XREAL SDK 3.1.0(Packages 안에 포함), 대상 기기 XREAL One Pro + Beam Pro(Android 14)
- 경품 서버 연동 토큰은 들어 있지 않습니다.
